RECON CAM V12.2 - INSTALL FROM IPHONE

1. Open the ZIP in Files and unzip it, OR download the index.html directly from ChatGPT.
2. Open https://github.com/nickolassantiago525-cell/recon-cam in Safari.
3. Replace the repository's root index.html with the new index.html and commit to main.
   In the GitHub mobile site, using the repository file editor to paste the new HTML
   is also possible. Do not keep two different index.html files in different folders.
4. Wait for GitHub Pages to finish deploying (usually a few minutes).
5. Open https://nickolassantiago525-cell.github.io/recon-cam/index.html?v=122
6. Check that the header reads V12.2 · FOCUS SCAN, not V12.1.
7. Tap the WEAPON badge and enable the experimental model. When it says READY,
   place a kitchen knife near the center of the camera frame and tap FOCUS SCAN.
8. Open the menu to see the last scan's TOP RAW SCORES. Scanning can take time.

HOW V12.2 DIFFERS
- Adds a close-up focus scan based on the visible center of the camera screen.
- Runs automatic full-frame scans around 14 seconds after the previous scan finishes.
- Allows sensitivity adjustment with warning about possible false matches.
- Displays raw candidate scores for diagnostics, even if nothing was outlined.
- Distinguishes a loaded model from completed scans.

IMPORTANT: This experimental AI can miss real knives and firearms or wrongly
label harmless objects. It has not been validated on an iPhone or for safety-critical
use. No detection is not evidence of safety. Phone and browser hardware limits apply.
Models require network access for downloads, and Safari controls camera permission.
